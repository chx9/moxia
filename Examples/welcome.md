# 欢迎使用墨匣

墨匣是一款为**微信公众号**而生的 Markdown 排版工具。左侧书写，右侧即见成稿；点击右上角的「复制」，即可直接粘贴到公众号后台编辑器。

> [!TIP] 从这篇示例开始
> 直接删掉这些文字，就可以开始写自己的文章。主题、强调色与排版设置都在标题栏和「设置」中。

## 写作，只需 Markdown

> 好的排版不喧宾夺主，它让文字自己说话。

- 支持标题、列表、引用、表格、分割线等常用语法
- 外部链接会自动转为文末脚注，例如 [Markdown 语法](https://commonmark.org/help/)
- 独占一行的图片会自动居中，并以 `alt` 文本作为图注

### 代码高亮

```swift
struct Greeting {
    let name: String

    func say() -> String {
        "你好，\(name)！"
    }
}
```

行内代码同样有样式，比如 `let x = 42`。代码配色可以在「设置 → 代码」中更换，也可以打开 Mac 风格窗口。

### 数学公式

质能方程 $E = mc^2$ 可以写在行内，也可以独立成块：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
